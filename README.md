# Authenstickator Docs

The documentation of Authenstickator, available at https://github.com/broland29/authenstickator/.
- build/thesis.pdf: the main documentation; its **section 4 presents the project and also contains setup steps**.
- other/presentation.pdf: a more interactive, short presentation of the project.
- other/summary.pdf: a two-page summary showing just the main ideas.

These PDFs were presented, along with [Release v1.0.2 of Authenstickator](https://github.com/broland29/authenstickator/releases/tag/v1.0.2), as my Master's thesis at the Technical University of Cluj-Napoca, on 9th of September, 2026.
